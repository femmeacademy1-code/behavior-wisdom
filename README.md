# חכמת ההתנהגות – דף נחיתה

Static Hebrew (RTL) landing page for חכמת ההתנהגות, a children's behavior and self-control training center in Stella Maris, Haifa.

- `index.html` – the page
- `css/nocturne.css` – Nocturne design-system base (buttons, cards, table, tags, nav)
- `css/site.css` – brand colors and signature treatments (gradient headings, highlights, icon badges)
- `js/main.js` – scroll-reveal animations (the page works without it)
- `assets/` – images, videos and doodle illustrations

Publishing: every push to `main` deploys to GitHub Pages via `.github/workflows/pages.yml`
(Settings → Pages → Source: **GitHub Actions**).
